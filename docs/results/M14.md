## Exact Harness Fix

**Repaired `harpoon/m14-test.sh:110` `log_file_for_sync()`** to:
- Take `variant` arg, determine `BIN_CHECK` (`harpoon-before`/`harpoon-after`/`harpoon/build/harpoon`)
- Query **authoritative path from tested binary**: `auth_path=$("$BIN_CHECK" logs --path 2>/dev/null | head -n1 | tr -d '\r\n')` (no hardcoded HOME)
- Enumerate candidates: `auth_path`, `"$HOME/Library/Application Support/Harpoon/harpoon.log"`, `/tmp/harpoon-runtime/harpoon.log`, `/tmp/harpoon.log`
- **Pick newest by mtime** via `stat -f %m` / `stat -c %Y`, not first-existing. This resolves sandbox vs primary divergence without hardcoding username.
- Fallback to `auth_path` or `home_log` if none exist.

**Robust port-sync window** (`run_tier_variant`):
- Verify `LOG_FILE` exists, else `PORT_SYNC_LOG_UNAVAILABLE` (do NOT convert to 0)
- `check_runtime` before and after window (PID + `harpoon status` + socket + `docker version` Server) — fail `RUNTIME_LOST_PORT_SYNC` if dead
- Record `WIN_START=$(date +%s)`, `sleep 60`, `WIN_END`, ensure `WIN_SECS` ~60
- Detect rotation: if `CUR_SIZE < OFFSET` reset offset
- `SYNC_COUNT=$(tail -c +$((OFFSET+1)) "$LOG_FILE" | grep -c "HARPOON_PORT_SYNC_START")` — only new entries, fail if not numeric
- `SYNC_PER_MIN="$SYNC_COUNT"` (60s window), do not synthesize zero

**Additional robustness:**
- **Config ambiguity fix:** `fromEnvironment()` prefers `~/Library/.../config.json` over `/tmp/...`, but `harpoon config set` writes to `HarpoonPaths.configFile` (sandbox-dependent). Fixed by writing both files `echo "{\"memory\":$tier,\"cpus\":2}" > "$HOME/.../config.json"` and `> "/tmp/.../config.json"` plus `HARPOON_MEMORY_MIB="$tier" "$bin" start` env var to guarantee tier.
- **VZ retry:** On `VZErrorDomain 1` retry once after 5s before declaring `HOST_VZ_START_FAILURE`.
- **Provenance preserved:** `harpoon-before` 2s vs `harpoon-after` 10s distinct hashes, `trap` restores `repeating: 10` on EXIT/INT/TERM, verified via `grep -q`.
