# Harpoon 2.0.0 release candidate

Status: candidate preparation only. Do not tag, push, publish, sign, notarize,
or call this a public release until the second-Mac acceptance gate passes.

## Current evidence

- 52/52 desktop tests pass.
- Frontend production build passes.
- Locked Tauri Rust check passes.
- Guest asset manifest and full guest verification pass.
- Guest asset and VM lifecycle offline regressions pass.
- Release preflight and `git diff --check` pass.
- Current package version is `0.1.1`; no `2.0.0` version bump or tag has been made.

## Hard blockers

- Native acceptance on a second Apple Silicon Mac is required.
- Intermittent `VZErrorDomain` startup failure remains unresolved; the new
  unexpected-VM-failure path has not been observed live.
- Ext4 journal follow-up, known log-producing container validation, and the
  Podman/rootless matrix remain incomplete.
- Developer ID signing, notarization, Gatekeeper assessment, DMG creation, and
  clean-machine packaged-app acceptance have not been run for this candidate.

## Candidate plan

1. Keep the current local checkpoint untagged and unpublished.
2. After source/provenance review, make a local `2.0.0-rc.1` version bump and
   commit it separately from functional changes.
3. Build an isolated app/DMG on the primary Mac only after the tree is clean;
   do not submit it for notarization yet.
4. Copy the candidate to a second Apple Silicon Mac and run the matrix below.
5. Fix and re-test any portability failures, then repeat the packaged-app
   checks on both Macs.
6. Only after acceptance: choose final `2.0.0` versus another RC, then obtain
   explicit approval for signing, notarization, tag, push, and publication.

## Log bundle

On the second Mac, collect only non-secret diagnostics into a new timestamped
directory. Do not copy `~/Library/Application Support/Harpoon/data/`, Docker
credentials, context metadata containing credentials, or private signing data.

```sh
OUT="$HOME/Desktop/harpoon-rc-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$OUT"
sw_vers >"$OUT/sw_vers.txt"
uname -m >"$OUT/arch.txt"
env -u HARPOON_BIN PATH=/usr/bin:/bin:/usr/sbin:/sbin \
  /Applications/Harpoon.app/Contents/Resources/harpoon/bin/harpoon doctor \
  >"$OUT/doctor.txt" 2>&1 || true
/Applications/Harpoon.app/Contents/Resources/harpoon/bin/harpoon status --json \
  >"$OUT/status.json" 2>&1 || true
codesign --verify --deep --strict --verbose=2 /Applications/Harpoon.app \
  >"$OUT/codesign.txt" 2>&1 || true
shasum -a 256 /Applications/Harpoon.app/Contents/Resources/harpoon/bin/harpoon \
  /Applications/Harpoon.app/Contents/Resources/harpoon/lib/harpoon/Image-virt \
  /Applications/Harpoon.app/Contents/Resources/harpoon/lib/harpoon/harpoon-initramfs.cpio.gz \
  >"$OUT/bundle-hashes.txt" 2>&1 || true
```

Add screenshots and a short timestamped reproduction note separately. Redact
usernames, paths, tokens, registry names, context endpoints, and container
identifiers before sharing.
