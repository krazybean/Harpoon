# Harpoon 2.0.0 release candidate (rc.2)

Status: `v2.0.0-rc.2` is an explicitly marked GitHub testing prerelease. It is
not stable `2.0.0`; `v0.1.1` remains the latest stable desktop release.

## Verified for this candidate

- Canonical `main` is based on `4503cde` after PR #100.
- Guest initramfs SHA256: `30f5a015ca8594bf55acd546e9a5a9d511f6a538c4696be4d698d95edcb96664`.
- Guest kernel SHA256: `d625d13a08f08ba1befa309edab7fa9360093b7e7c62b03010c0de084ff9ac20` (`6.12.110-0-virt`).
- Two full initramfs builds were byte-identical; the tracked manifest matches.
- One upgraded-host boot reached Docker-ready and management-ready; `doctor` reported 24 passed, 0 warnings, 0 failures, and an Alpine smoke container printed `NEW_GUEST_BOOT_OK`.

This is one upgraded-host smoke boot. It is not fresh-install evidence, second-Mac
evidence, or a 30-cycle cold-start result.

## Remaining gates

- Clean second-Apple-Silicon-Mac packaged-app acceptance.
- 30 cold boots on each of two Macs, with cleanup and recovery evidence.
- Upgrade and rollback with existing persistent state preserved.
- Developer ID application signing, DMG signing, notarization, stapling, and
  Gatekeeper assessment.

Do not describe this RC as notarized, Gatekeeper-approved, or stable until those
gates have actual captured results. Do not stop or restart a running Harpoon VM
to perform release verification; use the known-good backup and a disposable
runtime where the test requires it.
