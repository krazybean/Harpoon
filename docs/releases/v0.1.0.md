# Harpoon v0.1.0

First public release of Harpoon — a lightweight Docker-compatible container environment for macOS using Apple's Virtualization.framework.

## Highlights

- **Native macOS virtualization** — built directly on `Virtualization.framework` (no bundled third-party hypervisor)
- **Standard Docker Engine** — minimal Alpine Linux guest running Docker Engine 28.3.3, containerd, BuildKit
- **Docker CLI context compatibility** — `docker --context harpoon version/ps/run/build/buildx` via `unix:///tmp/harpoon-docker.sock` (`0600`)
- **Docker Compose support** — `compose build/up/down`, `env`/`.env`/`healthcheck`/`scale`/`mem_limit`, bridge networking, published ports
- **Compose project grouping** — desktop UI groups containers by `com.docker.compose.project`
- **Bind mounts through VirtioFS** — host↔guest sharing via `VirtioFS`, `ro` enforcement, named volumes, `/tmp/harpoon-share`
- **Named volumes & Docker networks/DNS** — `docker volume/network` management, bridge DNS, VZNAT + `virtio_net`
- **Published host ports** — dynamic `8372` loop handling via `PortForwardManager`, host `127.0.0.1` loopback forward, VZNAT guest IP discovery
- **Images/containers/volumes/networks management** — seven desktop views (overview, containers, images, volumes, networks, resources, diagnostics)
- **Resource configuration** — `cpus`/`memory` via CLI/env/config, `harpoon status --json`, `doctor`, `logs`, `config`
- **Diagnostics** — `harpoon doctor` (host/Harpoon/Docker), lifecycle state machine `STOPPED→RUNNING→FAILED`, `logs --path`
- **Apple Silicon** — macOS on Apple Silicon (arm64), ARM64 Linux guest

## Distribution

- **Desktop:** `Harpoon-0.1.0-arm64.dmg` — Tauri 2 + React app bundling runtime + Linux guest artifacts (kernel 33M, initramfs 14M, root 2G sparse)
- **CLI/runtime:** `harpoon-0.1.0-darwin-arm64.tar.gz` — relocatable `bin/harpoon`, `lib/harpoon/{Image-virt,harpoon-initramfs.cpio.gz,harpoon-root.img}`, install/uninstall scripts
- **Checksums:** `SHA256SUMS` with SHA-256 for both artifacts

Source builds remain supported: `bash harpoon/build.sh`, `npm --prefix ui/harpoon-desktop run build`, `cargo check`.

## Verification

- `file harpoon/build/harpoon` → `Mach-O 64-bit executable arm64`
- `codesign --verify --deep --strict` passes; `com.apple.security.virtualization` entitlement present (ad-hoc signing, not Developer ID notarization)
- `harpoon doctor` validates kernel/initramfs/disk, lock/socket state
- See `docs/results/` for M7–M18, EC, UI, D1/D1.1 evidence and `docs/building.md` for build/packaging verification

## Known Limitations for v0.1.0

- **Apple Silicon macOS only** — no Intel or cross-platform support
- **Distribution signing** — ad-hoc signing with `com.apple.security.virtualization`; Developer ID signing and Apple notarization are not complete for Gatekeeper distribution (`codesign --verify --deep --strict` passes locally, notarization not claimed)
- **Occasional Virtualization.framework startup condition** — an occasional host-side `VZErrorDomain Code=1` VM startup condition has been characterized (see `docs/results/R1.md`); same build succeeds when host healthy; retries are bounded, no automatic reboot
- **Disk** — 2 GiB fixed sparse `harpoon-root.img` (APFS clone-aware, no growable resize in v0.1)
- **Network/filesystem** — explicit `127.0.0.1` HostIp binding deferred (`0.0.0.0` → `127.0.0.1` safe default); `inotify` host→guest not propagated; `udp` port forwarding deferred; scoped/split DNS deferred
- **Memory reclamation** — balloon device present but host-visible reclamation was not consistently demonstrated; not marketed as guaranteed RSS reduction
- **Workflows** — CodeQL and Scorecard are configured; no successful public run is claimed until workflows complete on the public repository

See [README](https://github.com/krazybean/Harpoon#known-limitations--v01-scope) and `docs/roadmap.md` for full scope.

## Installation

- **DMG:** download `Harpoon-0.1.0-arm64.dmg` → open → drag `Harpoon.app` to `/Applications`
- **CLI tarball:** `tar -xzf harpoon-0.1.0-darwin-arm64.tar.gz -C /tmp && /tmp/harpoon-0.1.0-darwin-arm64/install.sh` (see `docs/installation.md` / `docs/building.md`)
- **Source:** `bash harpoon/build.sh` → `harpoon/build/harpoon`

Full prerequisites, signing, and troubleshooting in [Building](https://github.com/krazybean/Harpoon/blob/main/docs/building.md).
